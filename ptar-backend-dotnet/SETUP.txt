========================================================
  PTAR API — Backend .NET 10
  Equivalente al backend FastAPI Python
========================================================

PASO 1 — Instalar .NET 10 SDK
──────────────────────────────
Descarga: https://dotnet.microsoft.com/download/dotnet/10.0
(Elige "SDK" para Windows x64)

Verifica: dotnet --version  →  debe mostrar 10.x.x


PASO 2 — Restaurar paquetes y compilar
────────────────────────────────────────
cd ptar-backend-dotnet
dotnet restore
dotnet build


PASO 3 — Configurar credenciales
──────────────────────────────────
Las credenciales van en appsettings.Development.json (ya creado, NO se sube al repo).
El archivo ya tiene las credenciales de desarrollo preconfiguradas.

Para producción, usa User Secrets o variables de entorno:
  dotnet user-secrets set "ConnectionStrings:Default" "Server=...;Password=...;"
  dotnet user-secrets set "Jwt:Secret" "tu-secreto-aqui"


PASO 4 — Copiar token de SharePoint
─────────────────────────────────────
El archivo .sharepoint_token_cache.json ya existe en ptar-backend/
Solo copiarlo:
  copy ptar-backend\.sharepoint_token_cache.json ptar-backend-dotnet\.sharepoint_token_cache.json

(El token generado por Python MSAL es compatible con MSAL.NET)


PASO 5 — Correr el servidor
────────────────────────────
cd ptar-backend-dotnet\PtarApi
dotnet run

El servidor arranca en: http://localhost:8001
Swagger UI:            http://localhost:8001/swagger


PASO 6 — Cambiar puerto en el frontend
────────────────────────────────────────
El frontend React usa la misma URL http://localhost:8001
No necesitas cambiar nada en el frontend.

ESTRUCTURA DEL PROYECTO
════════════════════════
PtarApi/
├── PtarApi.csproj          ← paquetes NuGet
├── appsettings.json        ← config base
├── appsettings.Dev*.json   ← credenciales locales (gitignore)
├── Program.cs              ← startup + DI + middleware
├── Data/
│   └── PtarDbContext.cs    ← DbContext + IDbConnectionFactory
├── Services/
│   ├── JwtService.cs       ← crear/validar JWT
│   ├── SharePointService.cs   ← MSAL + REST API SharePoint
│   └── SharePointSyncService.cs  ← BackgroundService (sync cada 1h)
└── Features/
    ├── Auth/               ← login + /me
    ├── Caudales/           ← contadores agua
    ├── Reactivos/          ← químicos GEM/RO/PTAP
    ├── Calidad/            ← parámetros fisicoquímicos
    ├── Dashboard/          ← KPIs
    ├── Equipos/            ← estados equipos
    ├── Mantenimientos/     ← SharePoint mantenimientos
    └── Reportes/           ← PDF + HTML (QuestPDF)
